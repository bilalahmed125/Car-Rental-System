# 🚗 Car Rental Management System (JavaFX)

A **Car Rental Management System** built using **Java** and **JavaFX**, developed as a **Semester Project for Object-Oriented Programming (OOP)**.

This system provides a complete rental workflow for **customers** and **administrators**, managing multiple vehicle types with a clean and user-friendly graphical interface.

---

## 📌 Project Overview

This application simulates a real-world car rental business where:
- Customers can sign up, log in, and rent vehicles
- Admins can manage vehicles and monitor the system
- Multiple vehicle types are supported (because renting only cars would be boring 😄)

The project focuses heavily on **OOP concepts**, **clean design**, and **practical GUI-based interaction**.

## 🚙 Supported Vehicle Types

The system currently manages the following vehicles:

- 🚗 **Car**
- 🏍️ **Bike**
- 🚌 **Bus**
- 🚐 **Van**

Each vehicle type is handled using OOP concepts, making the system easily extendable (yes, adding trucks later wont require redesigning the whole system).

---

## 👤 User Roles

### 🧑 Customer
Customers can:
- Sign up and create an account
- Log in securely
- View available vehicles
- Rent vehicles based on availability
- Access their personal dashboard

### 🛡️ Admin
Admins can:
- Log in to the admin dashboard
- Add, update, or remove vehicles
- Manage vehicle availability
- Apply discounts
- Manage users (delete users)
- Oversee system data

(Admins don’t rent cars — they rule the system.)

---

## 🖥️ Application Features

- Separate **Login & Signup** for Customer and Admin (only login)
- Dedicated **Admin Dashboard**
- Dedicated **Customer Dashboard**
- JavaFX-based **Graphical User Interface**
- Well-structured OOP-based design

## ▶️ How to Run the Project

1. Make sure **Java JDK** and **Maven** are installed
2. Clone the repository
3. Open the project in **Code OSS / VS Code**
4. Run the `Main.java` file  
   *(This is the main entry point and contains the `start()` method)*
